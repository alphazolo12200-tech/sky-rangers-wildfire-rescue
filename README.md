# 🚁 Sky Rangers: Wildfire Rescue

A single-file HTML5 arcade game. Fly a firefighting aircraft, scoop water from the lake, read the wind, and put out the wildfire before time runs out.

▶️ **Play the demo:** https://YOUR-USERNAME.github.io/sky-rangers-wildfire-rescue/

## Features
- 3 aircraft: Rescue Heli, Water Scooper, Heavy Tanker
- 3 missions: Cadet, Ranger, Sky Ace
- Wind-driven fire spread, animated smoke, star-rated results
- Touch and keyboard controls, works on phones and desktop
- Procedural Web Audio sound, zero dependencies, runs offline

## Controls
- **Move:** drag on screen or arrow keys
- **Drop water:** DROP button or Space
- **Scoop:** fly low and slow over the lake
